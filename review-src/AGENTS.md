# 課後複習網頁：給 AI 助手（Codex 等）的工作規則

這個資料夾是「課後複習」網頁的**原始檔**。網頁本身在儲存庫根目錄的 `review/`，由程式產生。
網址：https://tnwang2010.github.io/edpsy/review/

## 最重要的一條

**不要直接修改 `review/` 裡的任何檔案。** 那是產生出來的結果，下次產生時會整個被覆蓋。
所有修改都改 `review-src/`，改完在儲存庫根目錄執行：

```
python3 review-src/tools/build.py
```

再把 `review-src/` 和 `review/` 的變更一起 commit。只需要 Python 3，不需要安裝其他套件。

## 檔案在哪裡

| 要改的東西 | 檔案 |
|---|---|
| 某一週的文字內容 | `review-src/weekNN/content.py`（例如第 1 週是 `week01/content.py`） |
| 某一週的投影片圖片 | `review-src/weekNN/slides/<key>.jpg` |
| 導覽欄的週次清單、新增一週 | `review-src/weeks.json` |
| 版面、顏色、字級 | `review-src/assets/review.css` |
| 網頁的結構（導覽欄、頁首、頁尾） | `review-src/tools/build.py` |

## content.py 的寫法

`BLOCKS` 是一個清單，依序就是網頁上的段落。每個項目是一個 tuple，第一個值是型別：

- `("label", "第 1 週｜教育心理學概論")`：標題上方的小標籤
- `("title", "…")`、`("dek", "…")`：標題與導言
- `("byline", "依王孜𡩋老師於「115學士後教育學分班」2026/10/08 課堂內容與投影片整理｜閱讀時間約 15 分鐘")`
- `("toc_label", "本文目錄")` 後面接 `("ol", [...])`：本文目錄，**項目必須和各個 `h2` 一一對應、順序相同**
- `("h2", "…")`：一節（網頁會自動加上「第 N 節」，不要自己寫編號）
- `("h3", "…")`：小節
- `("p", "…")`：段落
- `("ul", [...])`、`("ol", [...])`：清單
- `("img", "<key>", "圖說")`：投影片圖，`<key>` 對應 `weekNN/slides/<key>.jpg`
- `("note", "名詞解釋", [...])`：黃色說明框
- `("table", [[表頭…], [列…], …])`：表格，第一列是表頭
- `("h2plain", "資料來源")`：不編號的標題
- `("foot", "…")`：頁尾

文字中可用 `**粗體**` 與 `==螢光標示==`，其他 Markdown 語法不支援。

## 投影片圖片的來源

每週的投影片圖都取自王老師的 Google 簡報（第 1 週：https://docs.google.com/presentation/d/1ZddoQpoF_K5d4-Y594AfRRjVgY0xuZWPT7cfROGen54 ），`content.py` 開頭的 `SLIDES` 記錄每張圖對應的投影片 ID。
AI 助手**打不開這份簡報**，所以：

- 要換圖時，請老師提供該張投影片匯出的圖檔（Google 簡報：「檔案 → 下載 → PNG 圖片」，下載的是目前這一張），不要用螢幕截圖；截圖常會帶到「連結的投影片」按鈕等介面元素，或把邊緣切掉。
- 圖檔請存成 1600×900 的 JPG，覆蓋 `review-src/weekNN/slides/<key>.jpg`，並把 `SLIDES` 裡對應的 ID 一併更新（若老師有提供）。
- 只收到截圖、沒有原始圖檔時，請在 PR 說明中註明「此圖為截圖，建議改用投影片匯出圖」。

## 寫作規則（王老師的要求）

1. 只寫課堂上實際講過的內容，不寫課堂沒講的東西，不放同學的討論與發言。
2. 文體是部落格文章或專業報告：第三人稱、不口語，內文不寫「王老師說」。
3. 不放與課程無直接關係的題外話。
4. 圖說不寫投影片頁碼（p.xx），因為學生手上的投影片頁碼不同。
5. 不使用隱藏的投影片。
6. 老師的名字是「王孜𡩋」（𡩋 下面是「冉」），不要寫成其他字。
7. 名詞、年代、人名依投影片；文獻引用格式如 `(Kicken et al., 2009)`。

## 版面規則

- 本文最小字級 16px（相當於 12 號字）；導覽欄可以比本文小。
- 投影片圖片直接加細框線，不加底色。
- 修改 CSS 後，請確認手機寬度（約 375px）不會出現左右捲動。

## 新增一週

1. 建立 `review-src/weekNN/content.py`（可複製 `week01/content.py` 的結構）與 `review-src/weekNN/slides/`。
2. 在 `review-src/weeks.json` 把該週的 `topic` 與 `content` 填上（例如 `"week02/content.py"`）。
3. 執行 `python3 review-src/tools/build.py`。

## 不要動的東西

儲存庫根目錄的 `Page*.html`、`index.html`、`TBD` 等是「牛刀小試」的檔案，與課後複習無關，除非老師明確要求，不要修改。

## 提交方式

- commit 訊息用中文簡短說明改了什麼，例如「第 1 週：修正迷思一的統計數字」。
- 如果是透過 Pull Request 提交，請在說明中列出修改了哪幾週、哪幾節。
